# EQMonitor API を用いた地震履歴の検索

## 目的

EQMonitor API の接続先が設定されているとき、地震履歴を条件で絞り込めるようにする。
気象庁防災情報 XML と DM-D.S.S はカーソルの概念を持たないため、検索は EQMonitor API 専用とする。

## 前提

- `GET /v2/earthquake` のクエリパラメータをそのまま検索条件として使う
- 検索結果は既存の「過去の地震」一覧を置き換える
- 検索条件はアプリを終了すると失われる（永続化しない）

### API の制約

`next_token` をデコードすると `PAGING:<event_id>` であり、カーソルは `event_id` を基準に絞り込む。
そのため `sortBy` が `event_id` 以外のときにカーソルを併用すると、**結果に重複と欠落が生じる**。

実測（`sortBy=magnitude&sortOrder=DESC&magnitudeGte=1&limit=5`）:

| | 1ページ目 | 2ページ目 |
|---|---|---|
| 1件目 | `20110311144618` M9.0 | `20110311144618` M9.0（重複） |
| 2件目 | `20250730082807` M8.7 | `20130524144448` M8.3（重複） |
| 3件目 | `20130524144448` M8.3 | `20070113132313` M8.2 |

`event_id` が大きい `20250730082807` は飛ばされ、小さい `20110311144618` は再び現れる。
エラーにはならないため、**利用側で並び順に応じてページングを止める**必要がある。

## 構成

### 新規

| 要素 | 役割 |
|---|---|
| `EqMonitorSearchCondition` | 検索条件を表す record。API のクエリ項目に対応する |
| `EqMonitorEarthquakeSearchService` | 検索の実行と、検索結果のページング |
| `EarthquakeSearchView` | 条件入力のビュー。ダイアログとシートで共用する |
| `EpicenterRectSelectLayer` | 震央の矩形選択のプレビュー描画と、2点クリックの受付 |

検索サービスを `EqMonitorEarthquakeService` と分けるのは、後者が通常の受信のために
カーソル・失敗状態・受信元状態を既に抱えており、検索の状態を混ぜると双方が読みにくくなるため。
API クライアントの取得と `EarthquakePartial` → 情報フラグメントの変換だけを共用する。

### 変更

- `EarthquakeSeries`
  - `DisplayedEarthquakes` を追加する。通常時は `EarthquakeWatchService.Earthquakes` を、
    検索中は検索結果のコレクションを指す
  - 一覧のバインド先と、先頭の地震を参照している箇所をこちらへ寄せる
  - 検索の開始・解除、ダイアログの表示を担う
- `EarthquakeView.axaml` — 右上のボタン列に検索ボタン。一覧のヘッダに検索中の表示と解除ボタン
- `HistoryScrollLoader` — 検索中は検索サービスの追加読み込みを呼ぶ

`EarthquakeWatchService.Earthquakes` には書き込まない。検索の解除は参照を戻すだけで済む。

## データフロー

1. 検索ボタンを押すと、広い画面ではダイアログ、狭い画面ではシートを開く
2. 震央の緯度経度は「地図で選択」でダイアログを閉じ、2点クリックで矩形を決めてから開き直す
3. 「検索」で `SearchAsync(condition)` を実行し、`DisplayedEarthquakes` を検索結果へ差し替える
4. 一覧末尾までスクロールすると追加読み込みする。
   **並び順が発生時刻順以外のときは行わず**、その旨を一覧末尾に示す
5. 地震を選ぶと、既存の詳細取得（`GET /v2/earthquake/{eventId}`）がそのまま動く
6. 電文由来の新着を受信したら検索を解除して通常の一覧へ戻す。
   判定には既存の通知と同じ `IsBulkInserting == false` を使うため、
   EQMonitor の定期取り込みでは解除されない
7. EQMonitor が無効・未設定になったら検索ボタンを隠し、検索中なら解除する

## UI

### 検索ボタン

`EarthquakeView.axaml` の右上ボタン列に置く。
隣にある時刻表・ファイルのボタンは `IsDebugBuild` 限定だが、検索ボタンは
**EQMonitor の地震情報取得が有効なときに表示する**。

### 条件

常時表示:

| 項目 | 対応するクエリ |
|---|---|
| 発生日時の範囲 | `originTimeGte` / `originTimeLte` |
| マグニチュードの範囲 | `magnitudeGte` / `magnitudeLte` |
| 深さの範囲 | `depthGte` / `depthLte` |
| 最大震度の範囲 | `intensityGte` / `intensityLte` |
| 震央の緯度経度 | `latitudeGte` / `latitudeLte` / `longitudeGte` / `longitudeLte` |
| 並び順 | `sortBy` / `sortOrder` |

折りたたみの「詳細条件」:

| 項目 | 対応するクエリ |
|---|---|
| 長周期地震動階級の範囲 | `maxLpgmIntensityGte` / `maxLpgmIntensityLte` |
| 地震の種別 | `earthquakeType` |
| 電文の状態 | `statuses` |
| データソース | `datasource` |
| 電文種別 | `telegramTypes` |

### 震央の矩形選択

2点クリックで指定する。`MapLayer` には押下・離上のフックがなく、
ドラッグは地図のパン操作と競合するため。
2点クリックであれば**選択中も地図のパンと拡大縮小をそのまま使える**。

- 選択モードに入ると地図上に案内を出す（始点 → 終点）
- 1点目の確定後はカーソルに追従して矩形をプレビューする
- 2点目で確定し、ダイアログを開き直す
- Esc キーとキャンセルボタンで中止できる

### 検索中の一覧

ヘッダを「検索結果」に変え、件数と解除ボタンを出す。

## エラー処理

- **検索の失敗** — ダイアログを閉じずにエラーを表示する。条件を直してすぐ再試行できる
- **範囲の前後が逆** — エラーにせず入れ替えて検索する
- **結果が 0 件** — 一覧に「該当する地震情報はありません」と表示する
- **追加読み込みの失敗** — 既存の方針に合わせ、復帰するまで最初の 1 回だけログに残す

## やらないこと

- 検索条件の永続化
- 気象庁防災情報 XML・DM-D.S.S を対象とした検索
- `sortBy` が `event_id` 以外のときのページング（API 側の制約による）

## 検証

- 検索条件から組み立てたクエリ文字列が期待どおりであること
- 範囲の前後が逆のときに入れ替わること
- 実 API に対して、条件付きの検索とページングが重複なく動くこと
- 電文由来の新着で検索が解除され、EQMonitor の定期取り込みでは解除されないこと
